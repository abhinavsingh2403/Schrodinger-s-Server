# Held-out read-only trace replay
Metric proposed by agent, needs human review. Use only the last cached audited test day. Select the first five eligible complete sensor/session traces in deterministic hashed-session order. Require one or two command events with distinct timestamps between connect and close. Reject the whole trace if any command is missing or differs from a fixed literal identity or directory query. Do not trim, tokenize or pass through unknown text. Use canonical constants for SSH input. Report mutually exclusive exclusion counts.
Run the same five traces three times per arm in fresh Docker LAB_DEMO state per repeat. Request a PTY only for T2. Verify the final tier from the decision database. Count completion when the sensor logs the entire ordered input sequence; report the denominator and wrong-tier sessions separately. Discard transient logs with the volumes. This measures receipt of recorded inputs from one archive. It does not measure adaptive behavior or response fidelity.
