Reproduce with `python -m analysis.experiment1_spotcheck data/event_prefix_study`.

S2 anchors at first logged login success or failure, S4 at first command input and S5 at third command input. Require a connect and close on the same day, an anchor within that interval, one unambiguous source and an untied timestamp. Exclude prefixes already positive through the anchor. Use only events strictly earlier than the anchor for prediction. The future-only target is five distinct command inputs after the anchor, or a later upload, download or direct-TCPIP request. Prefix commands contribute zero toward those five. This differs from predicting the whole-session label conditional on an unresolved prefix.

Use elapsed whole seconds since connect, total prefix events, login attempts, failures, successes and distinct usernames at every stage. For command stages also use prefix command count, total length and token count, last command digest bucket (first hex digit), and whole-second gap between the last two commands, zero when absent. Cap numeric features at 255. Activity ranks by prefix event count (both signs). Compare expected random ties and the committed depth-three R7 tree using eligible rule inputs (success and failure counts). Freeze the strongest baseline by validation recall at 10%, ties broken in order random, positive activity, negative activity, R7. Remove activity/timing features together for ablation.

Split days chronologically. Exclude sources seen on earlier days, including validation sources from test, before feature fitting; persist counts. Use per-run secret HMAC for source linkage, never as a predictor. Train on up to 10,000 eligible sessions per stage ordered by hash of session key. Scale on train only. Use the existing balanced pure-Python logistic fit with C=0.01 and posthoc_ml_eval convergence. Freeze before one test evaluation. Report expected-tie recall and precision at 1%, 5%, 10%, 20% and full-curve PR-AUC. Fit permuted targets (seed 42), constant training prevalence, and ablation. At 10%, shuffle recall outside [0.08,0.12] invalidates the stage. Report test day separately (one date). Use paired source-cluster bootstrap, 10,000 resamples, seed 42, percentile intervals adjusted as in Experiment 0. Flag inadequate size as inconclusive. S1 and S3 lack verified boundaries.
Let delta = 0.05 absolute recall (the smallest improvement we would care about; fixed before seeing data).

- **PASS-ML:** there is a stage k in {S1, S2, S3} where Delta_k >= delta and the lower bound of its adjusted CI is above 0, with the minimum-size condition met.
- **PASS-LATE-ONLY:** no such stage in S1 to S3, but a stage in {S4, S5} meets the same condition.
- **FAIL:** otherwise.
